# In-progress milestones

A milestone plan moves here from `docs/planned/` when work on it starts. The
index in [docs/planned/WORK_PLAN.md](../planned/WORK_PLAN.md) is updated in
the same change.

When the milestone is verified, committed, and pushed, move the plan to
`docs/completed/`. Do not leave a finished plan here. The procedure is in
[WORKFLOW.md](../../WORKFLOW.md).
